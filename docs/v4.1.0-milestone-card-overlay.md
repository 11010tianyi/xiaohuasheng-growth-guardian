# v4.1.0 — 里程碑卡片科学详情弹窗 + 日记关联里程碑

## 版本概要

为所有里程碑/疫苗/体检/仪式卡片添加点击弹窗详情，展示科学解释（Markdown 渲染）+ 权威来源链接。日记编辑器新增里程碑关联下拉框，保存时自动编码为 `📌` 标签，查看日记详情时展示关联里程碑的科学解释。

---

## 1. 前端架构改动

### 1.1 `growth-guardian.js` — 共享详情弹窗

新增全局函数，所有页面共享：

| 函数 | 说明 |
|------|---------|
| `injectDetailOverlayCSS()` | 注入弹窗 CSS（覆盖层/卡片/关闭按钮/动画） |
| `window.findMilestoneItem(id)` | 遍历全部分阶段（0-1~9-10、vaccine、health、ceremony）查找里程碑项 |
| `window.findMilestoneByName(name)` | 通过显示名称模糊匹配里程碑项（v4.1.0 新增，用于日记标签反查） |
| `renderMilestoneDetailMarkdown(text)` | 使用 `marked` + `DOMPurify` 渲染 Markdown 为安全 HTML |
| `window.showMilestoneDetail(cardEl, event)` | 从 `data-milestone-id` 读取 ID，查找数据，渲染弹窗 |

**字段名归一化**：弹窗渲染时使用回退链支持多种数据结构：
- 标题: `item.title \|\| item.name`
- 建议时间: `item.suggestedTime \|\| item.age \|\| item.time`
- 描述: `item.desc \|\| item.content`
- 养育要点: `item.form \|\| item.importance`
- 额外信息: `item.cost`

## 2. 日记里程碑关联

### 2.1 状态变量（`diary.js`）

- `_selectedMilestoneId`（string）— 当前编辑器中选中的里程碑 ID
- `_milestoneItems`（array）— `{id, name, category}` 扁平数组

### 2.2 编辑器 UI

**新增 `.diary-milestone-selector`**（标签选择器下方）：

```html
<div class="diary-milestone-selector">
  <label>关联里程碑（可选）</label>
  <select id="diary-milestone-select">
    <option value="">不关联</option>
    <!-- 按 category 分组动态生成 -->
  </select>
</div>
```

- 使用 `<optgroup>` 按 category 分类
- `populateMilestoneSelect()` 在 `setupEditorEvents()` 中调用
- `change` 事件更新 `_selectedMilestoneId`

### 2.3 数据流

```
保存 (handleSave)
  ├─ _selectedMilestoneId 非空
  ├─ findMilestoneItem() 查找里程碑
  ├─ 编码为 "📌 {title/name}" 标签
  └─ 存入 tags[] + entryData._milestoneId

加载 (loadEntries)
  └─ 遍历 tags，匹配 "📌 " 前缀
     └─ findMilestoneByName() 反查 ID → entry._milestoneId

编辑 (editEntry)
  └─ 恢复 _selectedMilestoneId → 设置 <select> 值

重置 (resetEditor)
  └─ 清空 _selectedMilestoneId → 重置 <select>
```

### 2.4 详情展示（showEntryDetail）

关联里程碑的日记在底部展示：

1. **分隔线** + **"关联里程碑: {title}"** 标题（加粗衬线字体）
2. **科学解释**（Markdown 渲染）：超过 300 字符时折叠，显示"展开全部"链接
3. **参考来源**：浅色圆角背景块，来源名称可点击跳转（`target="_blank"`）

## 3. 页面改造

### 3.1 CDN 脚本加载

以下 5 个 HTML 页面在 `</body>` 前依次加载：

```
marked.min.js → DOMPurify → milestones-data.js → growth-guardian.js → 页面特有 JS
```

| 页面 | 说明 |
|------|------|
| `stage-0-3.html` | 0-3 岁阶段页（已有 CDN） |
| `stage-3-6.html` | 3-6 岁阶段页 |
| `stage-6-10.html` | 6-10 岁阶段页 |
| `health.html` | 疫苗/体检页 |
| `milestones.html` | 里程碑概览页 |

> `diary.html` 早在之前版本已加载 `marked` + `DOMPurify` + `milestones-data.js`

### 3.2 卡片点击绑定

所有 `.milestone-card` 元素添加：
- `data-milestone-id="{id}"`
- `onclick="showMilestoneDetail(this, event)"`

### 3.3 勾选框冲突解决

```js
// 复选框点击时阻止冒泡，避免触发卡片的 showMilestoneDetail
checkbox.addEventListener('click', function(e) {
  e.stopPropagation();
  // ... 原有打勾逻辑
});
```

## 4. 修复

### 4.1 未转义双引号（milestones-data.js）

`scientificDetail` 字符串中的中文引号 `"..."` 被解析为 JS 字符串结束符，导致 3 处语法错误。修复方式：替换为中文直角引号 `「...」`。
