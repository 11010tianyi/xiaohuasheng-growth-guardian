# ITEM_LINKS 跨区同步映射表

## 用途

`ITEM_LINKS` 定义各页面（里程碑/体检/疫苗/仪式）之间**同一实际事项**的 ID 映射关系。当一个事项在某个页面被勾选/取消勾选，同步传播到其他页面中所有关联的 ID。

定义位置：`growth-guardian.js` 第 39 行 `ITEM_LINKS` IIFE。

## 数据结构

```js
var ITEM_LINKS = (function() {
  var groups = [
    [id1, id2, ...],  // 同一事项的所有 ID
    ...
  ];
  var map = {};
  groups.forEach(function(group) {
    group.forEach(function(id) {
      map[id] = group.filter(function(x) { return x !== id; });
    });
  });
  return map;
})();
```

- 每个数组 = 该事项的全部跨区 ID
- 运行时展开为 `map[id] = [所有其他关联 ID]`

## 维护规则

### 何时新增分组

当体检/疫苗/仪式页面添加了新项目，且该事项在里程碑页面**已有对应条目**时，在 `groups` 数组中新增一行。

### 禁止重复 ID

**每个 ID 在 `groups` 数组中只能出现一次。** 如果一个事项跨越多个里程碑年龄（如"视力检查"出现在 8-9 岁和 10-11 岁），必须放在**同一个**数组内：

```
['s08-010', 's10-009', 'h-015']  // 正确
['s08-010', 'h-015']             // 错误: s10-009 被遗漏
['s10-009', 'h-015']             // 错误: s08-010 被遗漏
```

### 如何检测重复

```js
// 在浏览器控制台运行
var groups = ITEM_LINKS._groups; // 或直接从源码复制 groups 数组
var idCount = {};
groups.forEach(function(g, idx) {
  g.forEach(function(id) {
    if (!idCount[id]) idCount[id] = [];
    idCount[id].push(idx);
  });
});
Object.keys(idCount).forEach(function(id) {
  if (idCount[id].length > 1) {
    console.error('DUPLICATE:', id, 'in groups', idCount[id]);
  }
});
```

无输出 = 校验通过。

### 什么情况不做映射

以下疫苗剂量只在疫苗区出现，里程碑页面无对应条目，**保持独立**：

- 脊灰疫苗第2剂(v-004)、第3剂(v-008)、IPV加强(v-009)
- 百白破疫苗第1剂(v-012)、第2剂(v-013)、第3剂(v-014)
- 百白破四联第1剂(v-015)、第2剂(v-026)
- 乙肝疫苗第2剂(v-017)
- 轮状病毒第2剂(v-009)
- 仪式：新年仪式(c-016)、儿童节(c-017)
