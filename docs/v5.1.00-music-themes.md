## 2. 主题切换与持久化

### 2.1 UI

播放器右侧新增 `<select id="music-theme">` 下拉框，包含四个主题选项。当前主题显示为默认选中项。

### 2.2 切换逻辑

- 用户切换主题时，`currentTheme` 立即更新，主题偏好写入 `localStorage('gg_music_theme')`
- 如果当前正在播放，自动选取新主题的随机曲目并立即播放
- 如果已停止，仅保存主题偏好，下次播放时使用新主题

### 2.3 持久化 Key

| Key | 值 | 说明 |
|-----|-----|------|
| `gg_music` | `'on'` / `'off'` | 播放状态 |
| `gg_music_theme` | `'original'` / `'children'` / `'instrumental'` / `'ambient'` | 当前主题 |

页面加载时：若 `gg_music === 'on'`，按 `gg_music_theme` 恢复对应主题的随机曲目播放。

## 3. 主题色卡片指示器

### 3.1 功能

- 每个主题在 `THEMES` 对象中新增 `color` 属性
- 播放器曲名标签左侧显示 8px 圆形色点（`.theme-dot`），颜色与当前主题对应
- 色点使播放状态在视觉上更加直观，用户一眼即可识别当前主题类别

### 3.2 配色方案

```
原始主题  ● #F4A896 — 温暖桃色，柔和安心
儿童主题  ● #FFB5C2 — 甜美粉色，童趣可爱
轻音乐主题 ● #A8D5BA — 清新绿色，宁静舒缓
白噪音主题 ● #A8C8E0 — 淡雅蓝色，平静安眠
```

### 3.3 实现

- CSS：`.theme-dot` 为 8px 圆形，`border-radius: 50%`，`flex-shrink: 0`
- 标签容器改为 `display: flex; align-items: center; gap: 4px`，容纳色点 + 文本
- `showLabel()` 使用 `innerHTML` 动态渲染色点（`style="background: <color>"`）和曲名
- 停止播放时清空 `innerHTML`，色点消失

## 4. 数据流

```
页面加载
  ↓
localStorage('gg_music_theme') → currentTheme
  ↓
localStorage('gg_music') === 'on' → playRandom()
  ↓
pickTrack() → THEMES[currentTheme].tracks[randomIndex]
  ↓
audio.src = track.url, showLabel(track.name + colored dot)
  ↓
audio.play()
```

```
主题切换（change 事件）
  ↓
currentTheme = select.value
  ↓
localStorage('gg_music_theme') = currentTheme
  ↓
playing? → pickTrack() → audio.src = new URL → audio.play()
```

## 6. 已知问题与限制

- 主题色卡片仅显示在曲名标签中，主题下拉框 `<option>` 因浏览器安全策略无法自定义样式（色点仅在标签区域）
- freesoundslibrary.com 的 URL 路径包含 YYYY/MM，如文件被移除可能导致曲目失效，届时需替换为新的 CC 曲目
- 曲目选择为纯随机，不记忆上次播放的索引（设计决定，保持简单）
